# Aprenda a Criar Páginas e Sites

Página de vendas (landing page) do curso **"Aprenda a Criar Páginas e Sites"** — por Gabriel.

Curso gravado, low ticket, que ensina designers iniciantes a criar e vender landing pages profissionais do zero, mesmo sem saber programar.

## 📁 Estrutura

| Arquivo | Descrição |
|---------|-----------|
| `index.html` | Página de vendas completa (hero, módulos, bônus, oferta, garantia, FAQ) |
| `design-system.html` | Guia visual com cores, tipografia, botões e componentes |

## 🎨 Identidade visual

- **Tema:** dark tech / sci-fi com glow neon
- **Cores:** preto (`#070708`) + vermelho (`#ff1f2d`)
- **Fontes:** Sora (títulos) + Inter (texto)

## 🚀 Como visualizar

Abra o arquivo `index.html` no navegador, ou rode um servidor local:

```bash
# Python
python3 -m http.server 8000

# ou Node
npx serve
```

Depois acesse `http://localhost:8000`.
